# 🎮 坦克大战 (Tank Battle)

一个使用纯 HTML5 Canvas 制作的经典坦克大战网页游戏，无需任何依赖，直接在浏览器中运行。

![Tank Battle](screenshot.png)

## 🕹️ 操作方式

| 操作 | 按键 |
|------|------|
| 移动 | `W` `A` `S` `D` 或方向键 |
| 瞄准 | 鼠标移动 |
| 射击 | 鼠标左键 |
| 重新开始 | `R` 键 |

## ✨ 游戏特性

- 🎯 **鼠标瞄准** — 炮塔独立于车身旋转，鼠标精确瞄准
- 🧱 **两种墙体** — 可破坏的砖墙 + 不可破坏的钢铁墙
- 🤖 **AI 敌人** — 敌人会追踪玩家、躲避墙壁并开火攻击
- 🌊 **波次系统** — 消灭所有敌人进入下一波，难度逐渐提升
- 💥 **粒子特效** — 爆炸火花、弹道拖尾、碎片飞溅
- 🎁 **道具系统** — 击杀敌人随机掉落四种道具（回血、加速、速射、护盾）
- 🗺️ **小地图** — 右上角实时显示战场态势
- 📊 **HUD 显示** — 生命值、分数、波次、击杀数
- ✨ **视觉效果** — 无敌闪烁、受伤闪光、道具脉冲光晕

## 🚀 快速开始

1. 克隆仓库：
```bash
git clone https://github.com/BetaSmash-Z/tank-battle.git
```

2. 直接用浏览器打开 `index.html` 即可开始游戏！

或者直接访问 GitHub Pages: `https://BetaSmash-Z.github.io/tank-battle`

## 🎨 道具说明

| 道具 | 颜色 | 效果 |
|------|------|------|
| ❤️ 回血 | 绿色 | 恢复 2 点生命值 |
| ⚡ 加速 | 蓝色 | 移动速度提升 50%，持续 8 秒 |
| 🔥 速射 | 橙色 | 射击冷却缩短为 1/3，持续 8 秒 |
| 🛡️ 护盾 | 粉色 | 无敌 4 秒 |

## 🛠️ 技术栈

- 纯 HTML5 Canvas
- 原生 JavaScript (ES6+)
- 零依赖，单文件即可运行
